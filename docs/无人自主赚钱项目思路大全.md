# 无人自主赚钱项目思路大全

> 目标：在本机构建一套「多进程并行、可调度、可监控、可止损」的睡后收入体系。  
> 定位：不是暴富清单，而是可筛选、可验证、可落地的项目雷达。  
> 更新基线：综合 2025–2026 中外互联网主流实践（本地 Agent / 家用服务器自动化 / 微 SaaS / 内容资产 / 本地 B2B 服务）+ 经典资金型睡后收入（红利/REITs/国债等）。  
> 说明：收益率、国债利率、案例金额会随市场变化，文中数字仅作量级参考，落地前请核对最新公开数据。

---

## 0. 先建立正确心智模型

### 0.1 「完全无人」几乎不存在，真正可复制的是「可监督自动化」

更准确的目标不是「睡觉时完全不管」，而是：

1. **睡前**：把能力产品化、把验收标准写死、把危险动作加人工闸门  
2. **睡后**：系统自动接单 / 执行 / 交付 / 记账  
3. **醒后**：处理异常、复盘质量、扩容成功路径

一句话：

> 睡后收入 = 睡前把「可重复交付能力」固化成资产 + 睡后让系统重复变现

### 0.2 赚钱闭环公式（用它淘汰 80% 幻想项目）

```text
真实需求
  → 可标准化交付物
  → 本机可自动执行的动作
  → 质量/权限检查（关键动作人工审批）
  → 交付给客户或平台
  → 收款 / 复购 / 归因
  → 监控、止损、日志
```

缺任何一环（尤其是收款、验收、失败处理），都只是 Demo，不是生意。

### 0.3 睡后收入的四类资产（不要混为一谈）

| 类型 | 睡前投入 | 睡后形态 | 与本机 ProfitBot 关系 |
|------|----------|----------|------------------------|
| **资金型** | 本金 | 股息、分派、利息 | 本机可做监控/再平衡提醒，本身不靠算力赚钱 |
| **数字资产型** | 技能/审美/内容 | 模板、课程、素材、小程序广告 | 最适合本机自动上架、发货、更新 |
| **服务自动化型** | 流程打磨 + 获客 | 月费托管、Agent 交付 | ProfitBot 主战场 |
| **实物资产型** | 车/相机/房等 | 租金 | 本机可做定价、档期、客服，资产本身在线下 |

### 0.4 本机体系的三大技术层

| 层级 | 含义 | 例子 |
|------|------|------|
| 算力层 | 本机常开进程与调度 | Mac / PC / 旧电脑 + Docker + cron |
| 能力层 | 可复用的 Agent / 工作流 / Skill | n8n 流程、MCP 工具、本地 LLM |
| 变现层 | 有人付钱的闭环 | 月费托管、数字商品、API、联盟、服务费、广告 |

### 0.5 共同前提（与「零投入立刻躺赚」划清界限）

- **没有「零投入、零技能、立刻躺赚」**；若有，大概率是骗局  
- 睡前要么投入**资金**，要么投入**时间/技能**，要么两者都有  
- **收益越高，不确定性通常越大**：国债收益低但确定性强；业务/权益类弹性大、回撤也大  
- 选择依据只有三个：**本金多少、技能是什么、能承受多大波动**

## 1. 本机「ProfitBot」推荐总架构

```text
┌──────────────────────────────────────────────────────────┐
│                     调度中枢（Scheduler）                  │
│         launchd / cron / n8n / Prefect / 自研 orchestrator │
└───────────────┬───────────────────────────┬──────────────┘
                │                           │
        ┌───────▼───────┐           ┌───────▼───────┐
        │  内容与获客仓  │           │  交易与交付仓  │
        │ SEO/社媒/邮件 │           │ 店铺/API/发货 │
        └───────┬───────┘           └───────┬───────┘
                │                           │
        ┌───────▼───────────────────────────▼───────┐
        │              本地大脑（LLM）               │
        │     Ollama / 云 API（按任务分流）           │
        └───────┬───────────────────────────┬───────┘
                │                           │
        ┌───────▼───────┐           ┌───────▼───────┐
        │  数据与账本    │           │  监控与风控    │
        │ Postgres/SQLite│           │ 告警/限额/Kill │
        └───────────────┘           └───────────────┘
```

### 1.1 推荐技术栈（低成本、可本机）

- **编排**：自托管 n8n / Make（云） / 自写 Python + launchd
- **本地模型**：Ollama（Llama / Qwen 等）
- **浏览器自动化**：Playwright（登录态任务）
- **语音转写**：本地 Whisper
- **存储**：PostgreSQL 或 SQLite + 对象存储（网盘/S3）
- **支付**：Stripe / 微信/支付宝（视市场）/ Gumroad / 平台结算
- **告警**：Telegram / 飞书 / 邮件 / 短信
- **隔离**：Docker / 独立用户账号 / 独立浏览器 Profile

### 1.2 必须内建的 6 个安全阀

1. **人工闸门**：对外付款、公开发布、删改账号、真实资金交易，默认需审批  
2. **预算上限**：API、广告、短信、手续费日/月封顶  
3. **速率限制**：平台操作限频，防封号  
4. **可回滚**：草稿优先于正式发布  
5. **完整日志**：输入、输出、成本、结果、责任边界  
6. **一键 Kill Switch**：任意进程可秒停

## 2. 项目筛选评分表（落地前先打分）

每个想法用 1–5 分打分，总分建议 ≥20 再进入 7 天验证：

| 维度 | 问题 |
|------|------|
| 需求真实性 | 是否已有人在付钱？（不是「感觉有用」） |
| 交付标准化 | 能否一次定义、多次复用？ |
| 本机可运行 | 是否主要依赖本机调度，而不是必须坐在旁边？ |
| 无人化比例 | 日常是否 ≥70% 可自动？ |
| 边际成本 | 多一个客户/订单，成本是否接近 0？ |
| 合规风险 | 是否踩平台规则、版权、隐私、金融红线？ |
| 失败可承受 | 最坏情况是否可接受（钱、号、法律）？ |
| 验证速度 | 7–14 天内能否看到真实付款或明确否决信号？ |

说明：

### A. 本地 B2B 自动化托管（优先推荐）

这类最接近「本机睡觉赚钱」：卖的是结果，跑的是你的服务器。

#### A1. 本地商家评价回复引擎

- **做什么**：定时抓取 Google / 大众点评 / 美团等公开评价，本地 LLM 起草回复；好评自动发，差评推送给老板审批
- **收费**：¥99–¥1999 / 月 / 店
- **无人化**：A–B｜启动：低｜本机：★★★★★
- **本机流程**：cron → 抓取 → LLM 分类 → 自动回复/审批通知 → 月报
- **注意**：遵守平台 API / ToS；差评绝不自动公开回复

#### A2. 沉睡线索复活机器人

- **做什么**：导入客户 CSV，做 7–30 天短信/邮件唤醒；AI 应答常见异议，意向线索转人工
- **收费**：月费或成交抽成 5%–15%
- **无人化**：B｜启动：中（短信费）｜本机：★★★★☆
- **适合客户**：中介、健身房、汽贸、装修、教育机构
- **注意**：个人信息合规、退订机制、不得骚扰式群发

#### A3. B2B 内容二创工厂

- **做什么**：客户丢进一条长视频/播客 → 本机 Whisper 转写 → 拆成 LinkedIn/小红书/公众号/短视频脚本
- **收费**：¥300–¥3000 / 月
- **无人化**：A｜启动：低｜本机：★★★★★
- **优势**：边际成本极低；本地转写比云 API 更省钱

#### A4. 每日经营简报机器人

- **做什么**：汇总店铺订单、广告花费、库存、差评，每天 7 点发一份老板能看懂的简报
- **收费**：¥199–¥999 / 月
- **无人化**：A｜启动：低｜本机：★★★★★

#### A5. 预约与售后 FAQ Agent

- **做什么**：官网/企微/飞书自动答常见问题，复杂问题转人工并预约
- **收费**：安装费 + 月费
- **无人化**：B｜启动：低｜本机：★★★★☆

#### A6. 垂直行业「Agent 即服务」（AaaS）

- **方向例子**：律所文书初稿分拣、电商退货理由分类、外贸询盘评分、家政派单摘要
- **收费**：USD 500–5000+/月或按任务计费（海外更成熟）
- **无人化**：B｜启动：中｜本机：★★★★☆
- **关键**：越垂直越好卖；通用助手很难收钱

### B. 数字商品与「卖一次、交付无限次」资产

#### B1. 模板 / Skill / Workflow 商店

- **卖什么**：n8n 模板、Prompt 包、Cursor Skill、Notion / Canva 模板、在线课程片段、自动发货配置包
- **渠道**：Gumroad / Etsy / Lemon Squeezy / 爱发电 / 闲鱼 / 自建站
- **量级参考**：单价 $10 的模板月销 50 份 ≈ $500；做得好的垂直模板/课程常见月入四位数美元（高度依赖选品与流量，非均值承诺）
- **无人化**：A（售后除外）｜启动：低｜本机：★★★★★
- **本机增强**：Agent 自动上架、自动更新说明、自动发邮件交付
- **前提**：有可「封装」的技能或审美；从自己反复用过的东西产品化，比凭空造品更稳

#### B2. 垂直资料包（必须原创）

- **卖什么**：表格模板、SOP、检查清单、行业报告摘要、可复用脚本
- **无人化**：A｜启动：低｜本机：★★★★★
- **硬规则**：禁止盗版合集、破解软件、侵权题库；只卖你有权销售的原创/授权内容

#### B3. 微 SaaS / 单功能工具

- **例子**：Gumroad↔Printful 订单桥、评价摘要生成器、发票 OCR 归档、Niche 计算器、简历匹配评分
- **收费**：订阅 ¥29–¥299 / 月，或按次
- **无人化**：A（运维除外）｜启动：中｜本机：★★★★☆
- **策略**：先接 1–2 个服务客户验证，再产品化，避免一上来做大而全

#### B4. API / MCP 付费工具

- **卖什么**：给其他 Agent 调用的工具能力（搜索、清洗、行业数据、格式转换）
- **渠道**：RapidAPI、自建计量 API、MCP 市场
- **收费**：按调用量 / 订阅
- **无人化**：A｜启动：中｜本机：★★★★☆
- **2026 趋势**：Agent 经济里「卖铲子」（工具层）往往比「卖故事」更稳

#### B5. 许可制数字下载站

- **做什么**：本机生成/打包产品 → 自动上架 → Webhook 自动发货 → 授权码校验
- **无人化**：A｜启动：低｜本机：★★★★★

#### B6. 按需打印 / 代发货（POD / Dropshipping）

- **做什么**：你负责设计与获客，Printful / Printify / Redbubble 等负责生产物流；国内也可接代发供应链
- **平台**：Etsy、独立站、Shopify；设计可用 Canva / 本地生图流水线
- **无人化**：B｜启动：低–中（广告费）｜本机：★★★★☆
- **本机可做**：设计批量生成、上架文案、订单同步、缺货告警、评价催收
- **现实**：不碰库存是真的；但**营销能力决定生死**，红海品类竞争极烈，低质 AI 图案已高度饱和
- **建议**：先做超垂直主题（某职业/某圈层梗），再谈规模化；Dropshipping 比 POD 更吃选品与广告，新手优先 POD 小范围测图

#### B6b. 可封装技能的数字产品（电子书 / 课程 / 模板）

- **卖什么**：电子书、Notion/Canva 模板、在线课程、打印素材包、检查清单
- **平台**：Gumroad、Etsy、Shopify、爱发电、知识星球（偏社群）等
- **量级参考（公开转述）**：单价 $10 的模板若月销 50 份 ≈ $500；做得好的垂直产品有月入千级美元的案例，但均值远低于头部故事
- **无人化**：A（售后除外）｜启动：低｜本机：★★★★★
- **前提**：有可「封装」的技能或审美；本机负责生产、上架、邮件交付与迭代，获客仍要单独做

#### B7. 图库 / 视频素材销售

- **做什么**：向 Shutterstock、Adobe Stock、Pond5 等上传照片/视频；按下载分成
- **量级参考（公开转述）**：普通单张可能只有约 $0.25 量级；题材好的单次下载可到数美元；有存量高质量素材时，兼职月入约 $50–$300 较常见，全职做到更高取决于库存与题材
- **无人化**：A（上传后）｜启动：低｜本机：★★★★☆
- **本机可做**：元数据打标、关键词 SEO、批量上传、销量周报
- **前提**：已有或能持续产出**可授权**的高质量素材；纯 AI 图需核对各图库政策

#### B8. 微信小程序 / 轻应用（国内流量型）

- **做什么**：工具类、查询类、趣味类小程序，吃搜一搜自然流量 + 流量主广告 / 赞赏 / 内购
- **案例量级（公开转述，非承诺）**：
  - 极轻量趣味小程序：有成本约百元级、月余收入仅数十元、日均约 1–2 元的长尾案例
  - 多小程序矩阵：日活合计过千时，广告日入可到数十元量级
- **无人化**：A（上线后）｜启动：低｜本机：★★★★☆
- **本机可做**：内容/题库更新、崩溃监控、广告位实验、多小程序矩阵的版本发布
- **特点**：单品天花板往往不高，靠**数量 × 长尾搜索**；有技术门槛，边际成本极低
- **注意**：类目合规、用户隐私、诱导分享等平台规范；适合当「技术变现实验」，不宜当作主收入承诺

### C. 内容资产 × 联盟 / 广告（复利型）

#### C1. 超垂直内容站 + 联盟链接

- **做什么**：本机流水线：选题监控 → 大纲 → 初稿 →（人工终审）→ 发布 → 内链与联盟注入
- **变现**：Amazon Associates、ShareASale、国内联盟、站点广告位
- **无人化**：B｜启动：低｜本机：★★★★★
- **原则**：质量优先；全自动垃圾站短期可能有量，长期易被清洗
- **关键前提**：联盟营销赚的是**信任**；没有受众时，链接本身不产生收入。从零做号需要时间，本机自动化只能加速生产，不能跳过信任积累

#### C2. Newsletter 自动日报

- **做什么**：抓取行业源 → 摘要 → 排版 → 定时发送；靠赞助或联盟变现
- **无人化**：A–B｜启动：低｜本机：★★★★★

#### C3. 短视频切片工厂

- **做什么**：长视频 → 高光检测 → 裁剪字幕 → 多平台发布草稿
- **无人化**：B｜启动：中｜本机：★★★★☆
- **建议**：自动生成草稿，人工点发布，降低封号与版权风险

#### C4. 价格/折扣雷达站

- **做什么**：监控目标商品降价 → 自动发推文/电报/博客 → 吃联盟 Cookie
- **无人化**：A｜启动：低｜本机：★★★★★
- **注意**：遵守网站爬虫规则与联盟政策

#### C5. 超垂直招聘板

- **做什么**：抓取公开职位 → LLM 过滤某技术栈/远程条件 → 自动上站 → 向公司卖付费曝光
- **无人化**：A｜启动：低｜本机：★★★★★

### D. 电商与本地平台自动化（中国互联网高频）

#### D1. 闲鱼虚拟商品「选品→制作→上架→自动发货」流水线

- **闭环**：市场需求分析 → 原创制作 → 网盘上传 → 上架 → 付款后自动发链接
- **无人化**：A–B｜启动：低｜本机：★★★★★
- **本机组件**：闲鱼 MCP / 自动回复系统 / 网盘 MCP / 本地 LLM
- **关键风险**：平台风控、重复铺货、盗版内容、多店关联；必须限频 + 质量审核 + 真实售后入口

#### D2. AI 看店客服（售前 FAQ + 自动发货）

- **做什么**：常见问题自动答，议价有底线，付款自动交付，异常转人工
- **无人化**：B｜启动：低｜本机：★★★★★
- **原则**：Bot 吃重复工序；定价、退款、客诉必须人工终签

#### D3. 卖「铲子」：帮人部署自动化 / 卖配置

- **卖什么**：OpenClaw / n8n / 自动发货系统的安装、模板、巡检托管
- **收费**：一次性部署 ¥88–¥500+；托管 ¥300–¥800 / 月
- **无人化**：C→B（产品化后提升）｜启动：低｜本机：★★★★☆
- **优点**：验证快；可把自己用过的流程产品化

#### D4. 数字人直播补位（非完全替代真人）

- **做什么**：深夜/午休用数字人+话术引擎+OBS 推流；弹幕 AI 回复；商品轮播
- **无人化**：B｜启动：中｜本机：★★★☆☆

### G. 资金型睡后收入（本金驱动，本机辅助）

> 这是传统意义上最接近「躺着收钱」的一类：**钱在替你工作**。  
> 它**不是** ProfitBot 主航道，但应进入整体睡后收入组合——用它提供稳定底仓，用本机项目博取更高弹性。  
> 下列收益率多为阶段性公开信息的量级参考，**落地前务必核对最新数据**；均非保本承诺。

#### G1. 国内：高股息股票 / 红利 ETF（门槛相对低）

- **逻辑**：持有高股息资产，赚分红 + 可能的价格波动
- **常见观察**：A 股长期高股息标的多集中在银行、煤炭、家电、交通运输等；市场上常有一批股息率阶段性超过约 4% 的个股，其中部分能连续多年维持较高分红（数量与名单会变）
- **工具形态**：中证红利、红利低波、红利指数及相关 ETF（如红利低波类、宽基红利增强类等，代码随产品更新）
- **无人化**：A（买入持有 + 分红再投）｜启动：视本金｜本机：★★★☆☆
- **本机可做**：分红到账记账、持仓股息率监控、再平衡提醒、财报/除息日历
- **注意**：股息率随股价波动；分红后有除息；不是「固定 4% 无风险利息」

#### G2. 国内：公募 REITs（不动产收租，不用自己买房）

- **逻辑**：通过基金间接持有基础设施/保障房/消费园区等，获得分派
- **特点**：股票账户可买，门槛低于直接买房
- **量级参考（公开转述，会变）**：消费类、保障房类 REITs 的年化分派率常见大约在约 3%–5% 区间，不同产品差异大
- **无人化**：A｜启动：视本金｜本机：★★★☆☆
- **本机可做**：分派跟踪、折溢价监控、公告摘要推送
- **注意**：二级市场价格会波动，**非保本**；分派率 ≠ 你的实际持有期总回报

#### G3. 国内：储蓄国债 / 银行定存（最稳，收益通常最低）

- **逻辑**：极低风险换取确定票息；适合绝对安全偏好与短期用不到的钱
- **量级参考（公开转述，会变）**：近年储蓄国债 3–5 年期与大行定存，大致落在约 1.5%–1.8% 一带，往往难跑赢较高通胀预期
- **无人化**：A｜启动：视本金｜本机：★☆☆☆☆（几乎不需要系统）
- **定位**：现金管理与保底，不负责「增长」

#### G4. 国内：货币基金 / 纯债基金（比定存略灵活）

- **逻辑**：闲钱停车场；货币基金灵活性高、收益通常低于定存/债基；纯债波动大于货币
- **量级参考（公开转述，会变）**：货币基金 7 日年化中枢常见约 1% 上下；纯债基金中长期年化回报常见约 2% 上下（年份差异大）
- **无人化**：A｜启动：低｜本机：★★☆☆☆
- **本机可做**：七日年化跟踪、赎回提醒、家庭现金流调度
- **定位**：应急金与短期资金，不应当「主收益引擎」

#### G5. 海外：分红股 / 分红 ETF（Dividend Investing）

- **逻辑**：「股息贵族」（连续多年提高分红的公司）+ 分红 ETF；定投并自动再投资
- **时间成本**：配置完成后，每月管理常可压到 1–2 小时（再平衡/加仓检查）
- **前提**：合规的海外账户/通道；理解汇率、税务与平台费用
- **无人化**：A｜启动：视本金｜本机：★★★☆☆
- **本机可做**：定投执行提醒、分红再投核对、持仓日报
- **注意**：仍有股价波动；分红历史 ≠ 未来保证；十年分红翻倍的案例不能外推为承诺

#### G6. 高风险实验：量化 / 预测市场 / 链上跟随（默认不进主仓）

| 方向 | 现实 | 建议 |
|------|------|------|
| 量化交易 / 跟单 Agent | 回撤、滑点、过拟合、账户权限风险高 | 仅模拟盘 + 严格风控；真实资金需人工批准 |
| 预测市场套利 | 多为信息差/延迟博弈，方差大 | 当实验，不当工资替代 |
| 链上聪明钱跟随 | 叙事多、可验证少 | 先只读研究，不接热钱包全权 |

若一定要做：独立小资金账户、最大亏损硬限制、只读回放、独立对账、随时可关。  
**切勿**把 G1–G5 的「分红收息」心智，误套到 G6 的「主动交易」上。

## 4. 2025–2026 最新趋势提炼（可指导选型）

### 4.1 正在变强的方向

1. **B2B 无聊自动化**：评价回复、线索复活、内容二创、日报——比卖 AI 涂色书更赚钱  
2. **本地部署卖隐私**：律所/诊所/教育机构愿为「数据不出门」付溢价  
3. **Agent 工具层（MCP/API）**：给别的 Agent 提供能力，按调用收费  
4. **产品化服务**：先做服务验证，再做成单功能 SaaS / 模板  
5. **中国平台工序自动化**：闲鱼虚拟商品、自动发货、看店 Bot（但风控是主矛盾）

### 4.2 正在变弱 / 泡沫较大的方向

1. 纯「Mac Mini 插电躺赚」叙事（忽略 API 成本、维护、封号）  
2. 低质 AI 内容海量站（平台清洗加快）  
3. 无差异化 AI 自动化中介（供给过剩）  
4. 未经验证的自动交易截图故事  
5. 侵权数字资源批量铺货

### 4.3 一句选型口诀

> **优先：有人已在付钱 + 交付可标准化 + 本机能跑 + 失败可回滚**  
> **后置：金融投机 + 强对抗平台规则 + 处理敏感个人信息**

### 4.4 资金型 vs 本机项目：怎么搭配

| 你的情况 | 更该先做 |
|----------|----------|
| 有闲置本金、厌恶波动 | G3/G4 保底 + 少量 G1/G2；本机项目当「增长实验」 |
| 本金少、会写代码/做内容 | B/C/D/F 本机变现为主；资金型只放应急金 |
| 已有实物闲置资产 | I 类出租先盘活，再用本机做客服与档期 |
| 想「完全靠电脑印钞」 | 仍然先做 B/D 的可收款闭环，而不是一上来 G6 交易 |

### 4.5 按「本金 × 技能 × 波动承受」选型（DeepSeek 框架落地版）

```text
有较多闲置本金？
 ├─ 是，且极怕亏本金 → G3 国债/定存 + G4 货币（保底仓）
 ├─ 是，可接受净值波动 → G1/G2/G5 红利与 REITs（收益仓）+ 本机项目做增强
 └─ 否（本金少）
      ├─ 会写代码 / 会做自动化 → B8 小程序、B3 微 SaaS、D 闲鱼自动发货、A 类托管
      ├─ 有内容/审美/专业技能 → B1/B6b 数字产品、B6 POD、C 联盟内容、B7 图库
      ├─ 有闲置实物 → I 类出租
      └─ 几乎无技能无本金 → 先学一项可封装技能，再进 B/C；不要碰「躺赚课」与高杠杆交易
```

三条铁律：

1. **资金型**解决的是「钱的时间价值」，不解决「从 0 创造现金流」  
2. **本机项目型**解决的是「用技能换可重复收入」，波动来自市场与执行，不是净值曲线那么好看  
3. **收益预期必须和确定性匹配**：约 1.x% 的国债确定性强；约 4%–5% 的股息/分派伴随价格波动；业务收入可以更高，但也可能是 0

## 6. 多项目并行时的「进程编排」建议

把体系想成投资组合，而不是单押：

```text
资金底仓（建议单独管理）
  ：货币/国债/红利/REITs —— 提供确定性与流动性，不并入「实验仓」乱试

本机业务仓
  现金流仓（50%）：已验证可收款的自动交付（模板店、自动发货、月费托管、小程序广告）
  增长仓（30%）  ：内容/SEO/Newsletter/联盟，养复利资产
  实验仓（20%）  ：新 Agent、POD 新品类、新工具层
  禁止仓（0%）  ：未授权攻击、盗版、违法广告、无风控真实盘交易
```

每个项目进程统一实现这 5 个接口，方便你以后做成 ProfitBot 平台：

1. `start()` / `stop()`  
2. `healthcheck()`  
3. `run_once()`（可被 cron 调用）  
4. `report()`（今日成本、产出、收入、异常）  
5. `kill_switch()`

## 7. 合规与风控清单（务必当第一性原理）

### 7.1 硬红线

- 不卖盗版、破解、侵权题库、违禁品信息  
- 不未授权访问系统、不接黑灰产订单  
- 不处理身份证/病历/未成年人敏感信息做「AI 判断类」收费，除非具备完整合规能力  
- 不把真实资金交易权限交给无上限 Agent  
- 不批量违规多开、刷单、伪造评价

### 7.2 平台与版权

- 自动化必须遵守各平台 ToS；限频、真机环境、可人工接管  
- 内容与素材注意版权与肖像权（尤其数字人）  
- AI 生成内容按平台要求披露

### 7.3 财务与税务

- 每条流水可归因到项目与订单  
- **业务回款**与**股息/REITs 分派/利息**分栏记账，避免把投资收益误当成项目 PMF  
- 预留税费；对公/个体路径尽早想清楚；海外平台注意外汇与税务合规

## 8. 14 天最小验证剧本（通用）

### Day 1–2：选赛道

- 只选 1 个 P0  
- 写清：买家是谁、交付物是什么、怎么收款、失败怎么处理

### Day 3–5：打通闭环

- 本机跑通：输入 → 自动处理 → 输出 → 通知你  
- 先不要追求漂亮 UI

### Day 6–8：做出可卖版本

- 定价页 / 闲鱼链接 / Gumroad / 微信收款，任选一个  
- 准备 3 条售后 FAQ

### Day 9–11：找 10 个真实曝光

- 社群、熟人、垂直论坛、冷邮件、短内容引流，选一个渠道打穿

### Day 12–14：看三个数字

1. 是否出现真实付款（或明确拒绝原因）  
2. 单笔贡献毛利（收入 - API - 时间折合）  
3. 异常率是否可接受

**通过标准**：有回款，或学到「明确不可做」的证据。  
**失败也有价值**：快速杀死伪需求，把算力腾给下一条。

## 10. 附录：按「无人化潜力」速查

### 更接近无人（适合先做成常驻进程）

- 数字商品自动发货  
- 模板商店  
- 内容二创流水线  
- 评价好评自动回复

### 半无人（建议人工闸门）

- 差评回复  
- 对外销售邮件  
- 社媒正式发布  
- 闲鱼上新（限频+抽检）

- App / 小程序商店提交  
- POD 广告投放加预算

### 看起来很炫但不适合当主业睡后收入

- 全权自动交易  
- 无原创批量铺货  
- 强依赖违规多开的矩阵  
- 处理高敏感个人信息的「AI 咨询」  
- 无受众时的「纯挂联盟链接」幻想  
- 为追收益去高杠杆炒股/合约并称为「睡后收入」

## 11. 下一步（落到本仓库）

当你准备开始实施时，建议在本仓库按这个顺序演进：

1. `docs/` 保持思路与项目卡  
2. `apps/` 或 `projects/` 每个赚钱进程一个目录  
3. `orchestrator/` 统一调度、日志、成本、Kill Switch  
4. `ledger/` 简单账本（收入、成本、归属项目；**资金型分红与业务型回款分栏**）  
5. 先上线 **1 个能收款的 P0**，再并行第 2 个  
6. 若有闲置本金：单独建立 `ledger/capital.md` 记录 G 类底仓，不与实验项目混炒

**最后提醒**：  
真正能长期跑在本机上的，不是「最会讲故事的 Agent」，而是「交付稳定、成本可控、异常可接管、账能算清」的流水线。
